## One-line pitch

**Foundry is a B2B operating system where businesses spin up their own
"agencies" — purpose-built AI agent teams that hold the org's brand
soul, run autonomous missions, draft and publish social content, audit
websites, and chat with the team's Chief of Staff via the dashboard
or Telegram.**

Production URL: **https://foundryagents.ai** · Tagline: *Powered by SoulPrint Engine*.

---

## How Foundry is organised

- **Workspace** → **Organizations** → **Teams** → **Agents**.
- Each Organization has a **Soul** (mission, audience, tone of voice,
  values, north star, summary) that every agent in that org honors in
  every reply. The Soul gets synthesised on org creation from the
  user's mission statement or company URL.
- Each Team has its own **SoulPrint** layered on top of the org Soul,
  for finer specialisation (e.g. "Marketing Team" vs "Engineering Team"
  at the same org).
- **Memory is strictly org-isolated** — a fact stored in Org A's
  workspace cannot leak into Org B's agent replies.

## The agent catalogue

- A **150+ agent catalogue** of specialised divisions: marketing,
  sales, engineering, design, customer service, finance, ops, legal,
  HR, content, social, creative, growth, etc.
- A **Dynamic Intelligence router** picks the best agent for any given
  message — users can also @-mention or pin a specific agent.
- Every org gets a **Chief of Staff** agent automatically at creation:
  a senior generalist that triages, delegates, and answers anything.
- Power users can build **Custom Agents** via a per-org wizard
  (admin/owner gated).

## Missions (the autonomous engine)

- A **Mission** = give an agent a goal, it picks tools, researches,
  drafts, browses the web, generates images/videos, and ships
  deliverables — autonomously.
- **Mission Drafter** rewrites a rough user idea into a polished
  mission brief. Includes a **"Why this output?"** debug panel that
  shows which deterministic rules fired (social-intent detection,
  asset-library override, Social Queue routing, etc.).
- Tools the lead agent can call include: `web_search`, `browse_url`,
  `generate_image`, `generate_video`, `write_artifact`,
  `list_org_assets`, `draft_to_social_queue`, `read_org_documents`,
  and many more (Composio-backed: Gmail, Slack, Calendar, etc.).
- **Crucible / Agent Mode** is the next-gen mission runtime: tighter
  visibility into the agent's reasoning, paused-at-checkpoint UX, and
  Playwright-driven browsing.

## Social Queue (drafts → schedule → publish)

- Agents draft posts directly into a per-org **Social Queue → Drafts**
  tab. Each draft carries platform-specific variants, hashtags, and a
  cover image (or video).
- **Cover images** are auto-generated by **Gemini Nano Banana**, using
  the org's Soul + visual style guide for on-brand artwork.
- **Cover videos** (NEW) — render brand-aware short-form video covers
  via Kie.ai's marketplace: **Veo 3.1** (fast / full), **Kling 3 / 3 Pro**,
  **Seedance 1.5**, **Wan 2.6**, **Sora 2**, **Runway Aleph**. Aspect
  ratio auto-inferred from the platform (Reels / TikTok / Shorts → 9:16,
  LinkedIn / YouTube / Facebook → 16:9).
- **Asset Library integration** — users upload their own brand photos
  / product shots / team photos to the Media Library. Missions can
  `list_org_assets` and pass them as `asset_ids` to
  `draft_to_social_queue`; default behaviour is to **remix each asset
  through Nano Banana image-to-image** for an on-brand variant per
  post. Set `remix: false` to attach the original verbatim.
- **Two-click scheduling** — `QuickSchedulePopover` on every draft
  card. Pick a time slot, toggle auto-publish, done.
- **Bulk drafts via mission** — "Generate 7 IG posts about X" creates
  7 drafts in one mission turn.

## Publishing (live, no manual copy-paste)

- An **APScheduler tick** runs every 60s, promoting due `queued` posts
  to live publish via Composio.
- Supported auto-publish platforms: **LinkedIn**, **Facebook**,
  **Instagram (feed + Reels)**, **Reddit**, **TikTok (video + photo)**,
  **YouTube (video + Shorts)**.
- IG Reels uses the modern `media_type: REELS` container flow with
  status polling so Reels are never published before transcoding
  finishes.
- YouTube Shorts: vertical 9:16 ≤ 60s clips are auto-classified by
  YouTube itself. Default privacy is Public — overridable per-post.
- Auto-publish is **gated on cover media being ready** — a video draft
  won't fire until the mp4 finishes mirroring to GridFS.

## Asset Library

- Per-org **Media Library** at the org's "Org setup & insights" panel.
- Accepts **50+ file types**: images (png/jpg/webp/gif/svg/bmp/heic/avif/ico),
  documents (pdf/docx/rtf/pptx/xlsx), web pages (html/htm/xml/svg/rss/atom),
  structured data (csv/tsv/json/yaml/toml), code/config (py/js/ts/css/sql/sh/env),
  audio, video, archives. 10 MB per file.
- **Text extraction** runs on upload for prose-bearing types — HTML/XML
  tags are stripped (no script/style noise), PDFs and DOCX paginated,
  RTF cleaned. Extracts feed agent prompts so the org's reference
  material is implicit context.
- Categorisable (`product`, `lifestyle`, `team`, `venue`, `logo_variant`,
  `other`) with a `usable_in_social` toggle so users can mark which
  shots agents may pick for post covers.
- **Durable across redeploys** — every upload mirrors to MongoDB
  GridFS. If a Kubernetes pod migrates and wipes the ephemeral disk,
  the file rehydrates automatically on the next read.

## Business Audits

- Drop any website URL → get a scored brief (gaps, opportunities,
  a multi-viewport screenshot set, and a downloadable PDF) in ~90
  seconds.
- Great for prospecting (agencies use this as a lead magnet) and
  client onboarding.
- Audits are stamped with **OpenTimestamps** so the PDF's footer
  claims map to an actual Bitcoin Merkle-root anchor — verifiable
  document integrity.

## Telegram Chief of Staff

- Connect a Telegram bot to your workspace → your Chief of Staff agent
  becomes reachable via **DM on Telegram**. Same memory, same Soul,
  same tools as the dashboard chat.
- Useful for "while I'm away from the laptop" delegation: voice notes,
  file uploads, image generation, mission kickoffs, schedule lookups.

## Composio (3rd-party tool calling)

- Each org member can self-OAuth into **~25 SaaS integrations**:
  Gmail, Google Calendar, Slack, Notion, HubSpot, LinkedIn, Facebook,
  Instagram, Reddit, TikTok, YouTube, Linear, Jira, Asana, Google
  Drive, Dropbox, Discord, Salesforce, Mailchimp, Stripe, Calendly,
  Zoom, Twitter / X, Airtable, GitLab.
- Browse the full ~250-toolkit Composio catalog from the Connections
  panel.
- Multi-account per toolkit — connect "Work Gmail" + "Personal Gmail"
  with nicknames.
- Admins can toggle per-agent tool access — limit which agents can
  reach which integrations.

## Voice in / out

- **Voice in** via OpenAI Whisper — transcribe a voice note in any
  chat, including from Telegram.
- **Voice out** via OpenAI TTS — agents can speak their replies for
  hands-free workflows.

## Memory & isolation

- Per-user, per-org memory layer. Captures facts the user has stated
  ("I'm allergic to peanuts", "my brand colour is #FF6A00"), surfaces
  them as context on future turns.
- Strict org isolation — same user across two orgs gets two distinct
  memory namespaces.

---

## Billing & visibility

- Each workspace tracks **tokens, spend, and usage** in real time on
  the Spend Dashboard.
- Tiered pricing with overage tracking — usage above plan limits is
  metered and surfaced as overages (Phase B/C of the Stripe rollout
  is in progress; metered checkout + monthly invoice aggregation is
  on the near-term roadmap).

## Security & compliance

- Backed by **MongoDB Atlas**, **Kubernetes ingress**, and an
  org-isolated memory layer.
- **OpenTimestamps** anchoring for documents that require an integrity
  proof.
- **SOC 2 Type II** is **in progress** (see `/legal/soc2-roadmap` —
  Foundry is honest about its compliance state and does NOT claim
  certifications it doesn't hold yet).
- Per-toolkit OAuth credential management via Composio (SOC 2 + ISO
  27001 compliant).

---

## What Foundry is *not*

- Not a chatbot wrapper around a single LLM — it's a multi-agent,
  multi-tool platform with persistent state per org and team.
- Not a no-code platform — the Custom Agent wizard is closer to a
  "build your own specialist" flow than to drag-and-drop.
- Not yet SOC 2 certified — that's on the roadmap; the page at
  `/legal/soc2-roadmap` tells the honest story.
- Not a publisher — Foundry orchestrates publishing through Composio
  (which holds the platform OAuth tokens). Users connect their own
  accounts; Foundry never touches platform credentials directly.
